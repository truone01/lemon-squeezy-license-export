Lemon Squeezy license keys: export tool and migration guides

Lemon Squeezy stops processing payments on March 31, 2027, and Stripe Managed Payments does not deliver license keys. If your app calls the Lemon Squeezy License API, these pages help you keep paying customers unlocked.

Free tool

  • lemon-squeezy-license-export (MIT, no dependencies): export every license key and device activation to one CSV with your own API key. Also usable in the browser.
