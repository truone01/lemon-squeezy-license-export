Lemon Squeezy is shutting down: how to keep your license keys working

Lemon Squeezy stops processing payments on March 31, 2027. Its official path, Stripe Managed Payments, "doesn't deliver files, license keys, or download links" (Lemon Squeezy migration docs). If your desktop app, plugin, CLI or extension checks licenses through Lemon Squeezy, here is what breaks and what you can do.

What breaks

Apps that call Lemon Squeezy's License API (/v1/licenses/activate, /validate, /deactivate) lose those endpoints when Lemon Squeezy goes. Depending on how your app handles a failed check, paying customers get locked out or the app fails open. Every copy you've shipped needs to point somewhere else before that date, and users update slowly, so the change has to ship months early.

Checklist

  1. Find every place your app calls api.lemonsqueezy.com/v1/licenses/*, including old versions still in use.
  2. Export every license key and every device activation. The free export tool gives you one CSV. Re-export just before you switch.
  3. Choose where license checks will live (options below).
  4. Decide how new purchases get keys after you move checkout, for example a Stripe webhook that issues them.
  5. Ship an app update that points license checks at the new server, with a grace period, so a network error never locks out a paying user.
  6. Remember the update window: versions that still call Lemon Squeezy stop validating on March 31, 2027.

Keep the instance_id values. Your app got one back from each activate call and sends it on every validate. A new license server can honour existing activations only if it has them; without them, every customer has to activate again.
