Selling a WordPress plugin or theme through Lemon Squeezy? Plan the license and update move now

Lemon Squeezy stops on March 31, 2027. If your premium plugin or theme gets its updates through Lemon Squeezy's WordPress updater, or checks license keys against the Lemon Squeezy License API, both depend on Lemon Squeezy. Every site that runs your plugin needs a new version before then, and WordPress sites update slowly.

What depends on Lemon Squeezy today

  • Updates. Lemon Squeezy's docs describe sending update requests from your plugin to your own WordPress site running the Lemon Squeezy WordPress plugin, which only serves updates to customers "that have a valid license key". That check needs Lemon Squeezy's API and its license keys.
  • License checks in your code. If your plugin calls the License API itself (activate, validate, deactivate), those calls go to Lemon Squeezy.
  • New keys. Lemon Squeezy creates a key for each order. Its official path, Stripe Managed Payments, doesn't deliver license keys (Lemon Squeezy migration docs).

Why WordPress makes the deadline tighter

Many sites only update when the owner logs in, and auto-updates for premium plugins are often off. A copy that never gets your next release keeps calling Lemon Squeezy after it's gone. Ship the change that makes your license server replaceable in your next release, so it has months to spread before March.

Do these three things this month

  1. Copy your keys and activations out of Lemon Squeezy. The free export tool downloads every key and activation, including instance ids, into one CSV. It needs a read-only API key and keeps nothing.
  2. Put the license and update server URL in one constant or option in your plugin, instead of hard-coding Lemon Squeezy, and ship it.
  3. Decide what happens when the server can't be reached. A grace period (keep the plugin working, show a notice) is kinder than locking paying customers out. The License API guide has a short sketch.
